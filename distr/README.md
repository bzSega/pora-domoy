# Готовая версия для установки

## [↓ Скачать pora-domoy-latest.zip](https://github.com/bzSega/pora-domoy/raw/refs/heads/main/distr/pora-domoy-latest.zip)

Распакуйте ZIP и выберите папку extension через «Загрузить распакованное расширение» на browser://extensions в Яндекс Браузере. Node.js, Python и npm не нужны.

Текущая версия указана в VERSION.json. SHA256SUMS.txt содержит контрольную сумму ZIP. Пакет создаётся из extension/ командой npm run build.

Полная инструкция — в README репозитория и README.md внутри ZIP.
