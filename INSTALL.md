# Пора домой — установка

Это готовая версия расширения для Яндекс Браузера. Программы для разработки и сборка не нужны.

1. Распакуйте архив и переместите полученную папку в постоянное место на компьютере.
2. Откройте browser://extensions в Яндекс Браузере и включите режим разработчика.
3. Нажмите «Загрузить распакованное расширение» и выберите папку extension рядом с этим файлом. В ней находится manifest.json.
4. Закрепите значок «Пора домой» на панели браузера.
5. Откройте расширение, постройте маршрут по адресам работы и дома в Яндекс Картах. На вкладке Карт откройте расширение → «Взять из текущей вкладки» → «Сохранить и получить время».
6. При желании включите автообновление и выберите дни и часы.

Не удаляйте папку extension: браузер загружает расширение из неё.

## Обновление

Замените файлы в прежней папке extension файлами новой версии и нажмите перезагрузку на карточке browser://extensions. Не удаляйте расширение перед обновлением — удаление стирает настройки.
