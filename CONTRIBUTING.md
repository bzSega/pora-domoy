# Для разработчиков

Для установки готового расширения инструменты разработки не нужны — используйте ссылку в README.

## Проверка и сборка

Нужны Node.js 22+ и Python 3.10+.

```sh
npm test
npm run build
```

Сборка создаёт актуальный установочный ZIP в distr/, архивы для магазина и исходников в dist/, а также контрольные суммы. dist/ в Git не хранится. После изменений runtime пересоберите distr/ и включите обновлённый дистрибутив в тот же коммит.

## Браузерный тест

```sh
npm ci
npx playwright install chromium
npm run test:live
```

По умолчанию используется тестовый Chromium Playwright. Другой совместимый браузер можно указать локально через COMMUTE_TEST_BROWSER. Метод CDP Extensions.loadUnpacked должен поддерживаться выбранным браузером.

Тест создаёт отдельный временный профиль и использует публичный маршрут. Не указывайте основной профиль и не записывайте пути своей машины в код. Отчёты и снимки создаются в res/ и не попадают в Git.

## Изменения

Проверяйте затронутый сценарий: фоновое обновление, закрытая панель, смена направления, расписание, устаревший ответ и удаление данных. Сообщения от страниц считаются недоверенными; данные выводятся через textContent. Не включайте в изменения личные адреса, профили, токены или сторонние материалы без права распространения.

Об ошибках сообщайте через Issues или sergey@mikhaylov.com, используя публичный тестовый маршрут и диагностику без адресов. Уязвимости обсуждайте приватно — см. SECURITY.md.
