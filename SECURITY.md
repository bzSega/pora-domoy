# Безопасность

Поддерживаемая для исправлений ветка: 1.3.x beta. Обещанного срока реакции нет.

Уязвимости с возможностью чтения маршрутов или выполнения кода не описывайте в открытом Issue. Сообщайте о таких проблемах приватно на sergey@mikhaylov.com. GitHub Private vulnerability reporting можно использовать только если владелец включил эту функцию; её включение сейчас не подтверждено.

В отчёте достаточно версии, минимального воспроизведения на публичных координатах и описания воздействия. Не отправляйте cookies, профили браузера, чужие адреса или токены.

## Границы доверия

- Команды управления принимаются только от popup этого расширения.
- Время из iframe принимается только для текущего одноразового job и точного маршрута.
- Устаревшие ответы не восстанавливают удалённый маршрут.
- Строки страницы считаются данными и выводятся через textContent, не innerHTML.
- Хранилище закрыто от content scripts; код на страницах отправляет только разобранные поля.
- Страница Яндекса остаётся сторонним сайтом и подчиняется его условиям. Изменения сайта, капча и сетевые ошибки не обходятся.

MIT относится к нашему коду, не к данным и сервису Яндекса. Наличие MIT не подтверждает право коммерческой эксплуатации источника данных.
